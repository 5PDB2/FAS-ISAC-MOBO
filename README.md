# FAS-ISAC: Grey-Box Bayesian Optimization

Method implementation accompanying **Grey-Box Bayesian Optimization for ISAC in Fluid-Antenna Assisted Air-Ground Network**, by Gangyong Zhu, Jia Yan, Miaowen Wen, and Shijian Gao (accepted for publication in IEEE Transactions on Wireless Communications).

This initial release provides the grey-box optimizer and the ISAC simulation model.

Paper: [arXiv:2604.02181](https://arxiv.org/abs/2604.02181)
